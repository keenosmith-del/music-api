# Music Streaming Platform

## Overview

This project is a full-stack music streaming application built to demonstrate modern software engineering practices, scalable frontend architecture, backend API development, and complex application state management.

The application integrates with external music APIs to provide real-time artist, album, and track data while showcasing full-stack software engineering through RESTful API development, asynchronous data handling, reusable component architecture, global state management, and responsive design. Core functionality includes music search, synchronized playback, dynamic queue management, autoplay generation, artist and album navigation, and persistent data management.
